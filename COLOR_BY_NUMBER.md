# Color by Number Studio

A new browser-based tool in Project Bob. Open `color-by-number.html` to turn a local image into a numbered coloring puzzle.

## What it does
- Quantizes a picture into an adjustable 3–14 color palette.
- Splits the simplified image into connected regions and labels them by palette number.
- Lets you fill matching regions or fill all regions for one selected number.
- Includes undo, redo, reset, progress tracking, and PNG export.
- Processes images locally in the browser; it does not upload them.

## Use it
Open the GitHub Pages site and visit `/Doodle/color-by-number.html` (or open the file locally). Choose a PNG, JPG, or WebP image, set the palette and detail, and select **Make my puzzle**.

This is a local image-processing tool, not an AI game bot or a controller for a phone.
